## 🌆 Welcome to Pocket City

What if you could explore your college campus as an interactive digital city?

**Pocket City** is an independent campus visualization project created by an **ITER alumnus from the Class of 2025**, inspired by the Institute of Technical Education & Research (ITER), Siksha 'O' Anusandhan University, Bhubaneswar, Odisha.

It transforms a familiar university environment into an interactive 3D-style digital experience featuring academic buildings, hostels, gates, roads, greenery, animated traffic, seasonal environments and campus landmarks.

The project uses a custom-built Canvas rendering engine implemented with HTML, CSS and Vanilla JavaScript.

But Pocket City is about more than visualizing a university.

As a graduate, I wanted to create something meaningful for the campus community I was once part of. My goal is to encourage current ITER students and fellow alumni to explore the codebase, contribute improvements, learn Git and GitHub workflows, collaborate with other developers and build practical development experience.

Students can use meaningful project contributions as opportunities to develop their skills, strengthen their portfolios and build a genuine record of collaborative work.

**Built by an ITER alumnus. Improved by the ITER community.**

# ✨ Features

## 1. Interactive Campus Visualization

Explore a miniature representation of the ITER campus.

The application includes:

- Academic and administrative buildings.
- ITER Main Gate and secondary entrances.
- Central Library.
- ITER College Workshop.
- Research facilities and laboratories.
- Girls' and Boys' hostel compounds.
- Auditorium and sports facilities.
- Roads, pathways, lawns and parking areas.
- Campus boundaries and the Jagamara stream.

The campus environment contains 57 modeled structures and 8 named road/stream features.

## 2. Multiple Camera Presets

Explore different sections through dedicated camera viewpoints.

Available views include:

- Campus Overview
- Bird's-Eye View
- ITER Main Gate
- Gate 2
- Bansuri Guru Auditorium
- AIC-SOA
- Central Library
- Circular Building / Rotunda
- Boys Hostel 12

Navigation features include:

- Zoom in and zoom out.
- Camera rotation.
- Camera panning.
- 90-degree rotation.
- Slow camera orbit.
- Compass reset.
- Building label visibility.
- Campus boundary visibility.

## 3. Four Seasonal Environments 🌦️

Experience different visual representations of Bhubaneswar's seasonal climate.

| Environment | Visual Representation |
|---|---|
| Winter Dry | Clear skies, warmer sunlight and crisp shadows |
| Pre-Monsoon Summer | Golden ground, warm lighting and flowering trees |
| South-West Monsoon | Rainfall, wet roads, reflections and greener lawns |
| Post-Monsoon / Cyclone Season | Wind, slanted rain and changing illumination |

Seasonal presets modify the environment, vegetation, ground appearance and lighting.

## 4. Campus Occasions and Special Lighting 🎉

The project also features four campus atmosphere presets:

- Regular Academic Day
- Chakravyuh & Genesis Fest
- SOA Foundation Day
- ITER Graduation Day

Occasion-related visual elements include fest stage structures, fairy lights and graduation decorations.

## 5. Animated Campus Traffic 🚗

The campus is not just a static collection of buildings.

The traffic system represents a predefined circulation layout following Indian left-hand traffic rules.

Includes:

- Animated buses.
- Cars and scooters.
- Auto-rickshaws.
- Vehicle movement along campus roads.
- Animated pedestrians.
- Campus road circulation and junctions.

## 6. Searchable Campus Directory 🔍

Find campus locations through a searchable directory.

The current directory contains 65 entries covering modeled campus structures and named road/stream features.

Users can:

- Search buildings, hostels, gates and roads.
- Filter locations.
- Select a landmark.
- Move the camera towards a selected location.
- Open the landmark inspector.
- Access available map references.

## 7. Interactive Landmark Inspector 📍

Select a campus landmark to view its information.

Depending on the selected entry, information can include:

- Landmark name.
- Category and description.
- Additional specifications.
- Local coordinates.
- Geographic map coordinates.
- Google Maps navigation.
- Satellite and Street View links.
- Available photo previews.

## 8. Google Maps Photo Synchronization

A dedicated photo management interface helps enrich the campus directory.

Supported workflows include:

- Optional Google Maps Places API integration.
- Manual photo URL entry.
- Local photo uploads.
- Individual landmark photo synchronization.
- Bulk synchronization.

Google Maps photo synchronization requires suitable API access and a valid API key. External maps and photographs depend on provider availability and internet access.

## 9. Campus Vegetation 🌳

The application includes more than 100 modeled trees and palms.

Regional vegetation representations include:

- Krishnachuda / Gulmohar.

## 10. Responsive Interface 📱

The interface adapts to desktop, tablet and mobile layouts.

Input support includes:

- Keyboard interactions.

The goal is to make campus exploration accessible across different screen sizes.

# ⚙️ Technical Architecture

One of the most interesting parts of Pocket City is its rendering implementation.

The project does not require a conventional third-party 3D framework.

Instead, the application uses the Canvas 2D API with custom JavaScript geometry, projection and depth-sorting logic to create a 3D-style environment.

## Custom Rendering Pipeline

The main rendering system includes:

1. Local coordinate transformations.
2. Camera positioning and projection.
3. Custom geometry construction.
4. Per-part depth calculation.
5. Topological painter's sorting.
6. A four-pass rendering pipeline.
7. Continuous animation through `requestAnimationFrame()`.

This allows buildings and their individual parts to be rendered according to their relative depth.

## Coordinate System

The project uses a local campus coordinate system.

| Axis | Direction |
|---|---|
| +X | East |
| +Y | North |
| +Z | Up |

Additional coordinate parameters:

- Scale: 1 world unit = 1.47 metres.
- Reference origin: 20.24781°N, 85.80127°E.
- Rotation: Radians.
- 90-degree rotation: `Math.PI / 2`.

The system also includes local-to-WGS84 coordinate conversion for geographic links and Google Maps navigation.

These model coordinates are intended for visualization, not survey-grade positioning.

# 💻 Getting Started

## Requirements

- A modern desktop or mobile browser.
- Git for cloning the repository.
- Internet access for external map previews and online services.

No Node.js installation or framework setup is required.

## 1. Clone the Repository

```bash
git clone https://github.com/Punitpritam788/Pocket-City-ITER.git
```

## 2. Open the Project

```bash
cd Pocket-City-ITER
```

Open `index.html` in a modern browser.

If the original downloaded filename is different, rename it to `index.html` first.

## 3. Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Navigate to Settings.
3. Select Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` as the branch.
6. Select `/ (root)` as the folder.
7. Save the settings.
8. Open the generated project-site URL.

# 🧩 Developer Guide - How to Contribute

## Built by an Alumnus. Open to the ITER Community.

Pocket City was created by an ITER Class of 2025 alumnus with the intention of giving something back to the campus community.

One of my main goals is to create an opportunity for current students and fellow alumni to participate in a real development project.

You do not need to build an entire application from scratch to make a meaningful contribution.

You can start by:

- Correcting a building's location.
- Adding a missing campus landmark.
- Improving the mobile interface.
- Fixing a visual bug.
- Improving documentation.
- Optimizing a JavaScript function.
- Adding a new geometry builder.

The goal is to learn through actual development work, collaborate with others and create genuine contributions that can be demonstrated in a developer portfolio.

## Contribution Idea 1: Add or Modify a Building

Find:

```javascript
// [JS: BUILDINGS]
```

Locate the `LANDMARKS` array.

Each landmark contains properties such as:

```javascript
{
  id: 'your-building-id',
  category: 'Academic Blocks',
  name: 'Your Building Name',
  shortLabel: 'Building',
  badge: 'Campus Landmark',

  x: 10,
  y: 20,
  w: 12,
  d: 10,
  h: 8,
  angle: 0,

  desc: 'Description of the building.',

  specs: {
    'Type': 'Academic Building',
    'Location': 'Campus Area'
  }
}
```

Use verified campus information when modifying building coordinates, names and descriptions.

## Contribution Idea 2: Build Custom 3D Geometry

Find:

```javascript
// [JS: BUILDERS]
```

You can add a custom builder function for a structure that needs more detail than the automatic multi-storey block renderer.

Connect the new builder to the rendering switch using the relevant landmark ID.

This is a useful way to experiment with geometry construction and the rendering pipeline.

## Contribution Idea 3: Improve the Campus Environment

Possible areas include:

- Campus boundary accuracy.
- Road geometry.
- Architectural details.
- Parking layouts.
- Vegetation and landscaping.
- Lighting and environmental effects.
- Vehicle and pedestrian animation.

## Contribution Idea 4: Improve the Interface

Frontend contributions can focus on:

- Mobile responsiveness.
- Directory search.
- Inspector layout.
- Touch controls.
- Keyboard accessibility.
- Visual consistency.
- Performance.

## Contribution Idea 5: Documentation and Research

You can also contribute without writing new code.

Examples:

- Verify landmark names.
- Research missing campus facilities.
- Document building positions.
- Report incorrect descriptions.
- Create screenshots.

# 🤝 How to Contribute Using GitHub

Contributions can follow a standard fork-and-pull-request workflow.

### Step 1: Fork the Repository

Open:

https://github.com/Punitpritam788/Pocket-City-ITER

Click Fork to create your own copy.

### Step 2: Clone Your Fork

```bash
git clone YOUR_FORK_URL
```

### Step 3: Create a New Branch

```bash
git checkout -b feature/your-improvement
```

### Step 4: Make Your Changes

Follow the existing code structure and navigation tags.

Try to keep changes focused on a specific improvement.

### Step 5: Test Your Changes

Check:

- Campus rendering.
- Building placement.
- Overlapping geometry.
- Depth sorting.
- Desktop and mobile layouts.
- Existing camera controls.
- Directory and inspector functionality.
- Browser console errors.

### Step 6: Commit Your Work

```bash
git add .
git commit -m "Improve campus landmark rendering"
```

### Step 7: Push Your Branch

```bash
git push origin feature/your-improvement
```

### Step 8: Open a Pull Request

Explain:

- What you changed.
- Why the improvement was necessary.
- Which files you modified.
- How you tested the change.

Add screenshots when your changes affect the visual appearance.
